# BRD (Business Requirements Document)

## 1. 프로젝트 목적
Sean의 자기소개를 웹 페이지 형태로 제공하여, 누구나 브라우저에서 쉽게 열람할 수 있도록 하는 것이 목적입니다.

## 2. 자기소개 페이지가 필요한 이유
- 텍스트 파일(`person_information.md`)만으로는 가독성과 전달력이 부족합니다.
- 정적 HTML 페이지로 만들면 브라우저로 바로 열람할 수 있어 공유가 용이합니다.
- HTML/CSS/JS 기초 학습 및 실습 목적도 함께 충족합니다.

## 3. 대상 사용자
- Sean을 처음 알게 되는 동료, 지인
- 자기소개 페이지를 참고하려는 학습자 (HTML/CSS/JS 입문자)

## 4. 페이지에 포함할 주요 정보
- 기본 정보: 이름, 나이, 직업
- 취미 목록
- 한 줄 소개
- 좋아하는 색깔

## 5. 기대 효과
- Sean에 대한 정보를 시각적으로 정돈된 형태로 전달할 수 있습니다.
- 웹 페이지 제작 기본 흐름(HTML 구조 → CSS 스타일 → JS 인터랙션)을 학습할 수 있습니다.
- 향후 포트폴리오 페이지로 확장할 수 있는 기반이 됩니다.

## 6. 제외할 범위
- 백엔드 서버 및 데이터베이스 연동은 포함하지 않습니다.
- 회원가입, 로그인 등 인증 기능은 포함하지 않습니다.
- 외부 프레임워크(React, Vue 등) 및 빌드 도구는 사용하지 않습니다.
- 다국어 지원, 반응형 고도화(모바일 최적화 외)는 이번 범위에서 제외합니다.
