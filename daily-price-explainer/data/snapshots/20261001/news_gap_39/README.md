# 뉴스 공백 39일 로컬 전달 기록

2026-10-01 Codex. 대상 2026-08-04~2026-09-30의 지정 39거래일.
일반 웹 검색으로 기사 57건, 검색 로그 39건을 기존 두 JSONL에 추가했다.
배치 1: 20일/32기사. 배치 2: 19일/25기사. 모두 unreviewed.
Claude Code의 후속 검증·중복제거·병합을 위한 로컬 결과이며 커밋·푸시는 아직 하지 않았다.

`OUTPUT_FOR_CLAUDE.md`에는 실제 추가된 JSONL 전부와 검증 해시가 있다.
현재 작업폴더의 파일에는 이미 추가됐으므로 이 출력물을 다시 append하면 중복된다.

`validation_summary.json`: 스키마 57건, 대상 날짜별 로그 정확히 1건, URL/ID 중복 없음,
거래일 귀속 및 로그 기사 수 일치, 기존 바이트 SHA-256 보존을 검증했다.
`batch01_manifest.json`, `batch02_manifest.json`: 각 배치 전후 SHA-256과 추가분 해시.
`note_correction_manifest.json`: 배치 2의 조선비즈 시각 출처 설명에서 ‘수정시각’을
‘화면 입력 표기’로 고친 1개 notes 문구의 전후 해시. 기사 속성값은 그대로다.

검색 범위와 해석:

- `search_queries.json`은 날짜별 SK스퀘어 검색, 적응형 SK하이닉스 보완검색,
  보유자산 월별·기간별 검색을 기록한다. 확인한 일반 웹 검색 결과의 수록이며 기사 전수 망라를 뜻하지 않는다.
- 가격·잔차 CSV는 라벨 판단에 사용하지 않았다. 가격 시황 27건은 sentiment와 ex ante 방향 모두 0이다.
- 본문 전체를 웹 도구/검색에서 확인한 29건은 full_text, 일부만 확인한 28건은 partial_text다.
  로컬 HTTP가 403이더라도 웹 도구나 검색에 본문이 있었던 기사까지 metadata_only로 낮추지는 않았다.
- `receipts_01.json`, `receipts_02.json`에는 URL, HTTP 상태, 발행 메타와 확보 가능한 본문 컨테이너 해시만 저장했다.
  저작권 본문 원문은 저장하지 않았다. 본문 컨테이너를 확실히 선택하지 못한 원천은 hash=null이다.
- ID는 SHA256(URL + '|' + (본문해시 또는 빈 문자열))이다. 해시가 있는 본문은 선택자 텍스트를
  공백 정규화한 UTF-8로 계산했다. 각 receipt에 선택자와 해시 계산식을 적었다.
- 뉴시스 일부 HTML published_time은 수정시각이어서 화면 최초 등록시각을 사용했다.
  조선비즈 9월 30일 기사는 발행 메타 08:47:54.812 KST와 화면 입력 08:50이 다르다.
  메타를 사용했으며 두 시각 모두 개장 전이어서 귀속은 동일하다. 이 차이는 logs notes에 남겼다.
- 공개시각을 확정하지 못한 일부 IonQ 실적·투자자 행사 원문은 임의 시각을 만들지 않고 제외했다.
  검색 날짜와 제외 사유는 로그에 남겼다. 모든 기사에서 surprise는 비교 가능한 확정 기준이 부족해 unknown이다.
- 후속 IPO 비판의 부정 방향은 본문에 명시된 희석·지배구조 우려에 근거한다.
  신작·서비스·ESG 및 공시봇 기사의 관련성·중요도는 낮게 구분했다.

후속 검증은 `.venv\Scripts\python.exe -X utf8 data/snapshots/20261001/news_gap_39/validate_delivery.py`로 재현할 수 있다.
`build_batch.py`는 재실행 시 기존 배치 파일/로그 중복을 거부한다. fetch/normalize/correct 스크립트는 작업 당시 보조도구이므로 재실행하지 않아도 된다.
정량 CSV·NAV·스케줄러·뉴스 실험은 이번 작업에서 변경하거나 실행하지 않았다.
