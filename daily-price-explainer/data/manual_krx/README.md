# 수기 시장 데이터 원본

브라우저 또는 HTS에서 내려받은 원본 파일을 그대로 보존한다. `factor_log.csv`는
직접 편집하지 않고 검증된 임포터로 갱신한다.

## ⚠ 규칙

- **다운로드한 원본을 그대로 둘 것.** 컬럼명과 파일 형식을 바꾸지 않는다.
- 기존 `factor_log.csv`는 사본 검증·해시 대조 뒤 원자적으로 교체한다.

## F4 기준일과 재개 준비

2026-10-01 Sean 확정: 새 F4 원본은 **실제 당일 값**을 해당 기준일에 저장한다.
과거 레거시의 하루 밀림은 보존한다. 잔고증감은 실제 D 잔고와 실제 직전 거래일
잔고의 차이이며, 날짜 의미가 혼합된 레거시 CSV를 신규 차분 원천으로 쓰지 않는다.
`tools/short.py`와 로거는 요청일과 응답일이 맞는 자료만 사용한다. 미공시·조회 실패는
빈 값으로 남기고, 당일 거래비중은 잔고 공개 여부와 독립적으로 수집한다.

남은 2행 템플릿은 이전에 입력된 원본과 별도로 준비했다. 잔고수량·잔고증감을
KRX 포털에서 실제 기준일로 확보한 뒤 입력한다. 09-30 거래비중도 빈칸이며,
09-29 거래비중은 이미 복구됐으므로 다시 입력하지 않는다. 잔고비율은 자동 계산이다.

```powershell
.\.venv\Scripts\python.exe tools/apply_shorting_manual_input.py --factor-log <검증용 CSV 사본> --workbook data/manual_krx/shorting_gap_input_remaining_402340.xlsx
```

사본에 `--apply`해 변경 셀·전후 SHA-256을 확인한 뒤, 실제 파일에도 확인한 원본
해시를 `--expected-sha256`으로 지정해 원자적으로 반영한다. 변경 후 감사 도구를
실행한다. 2021-11-30 잔고증감은 정상 결측으로 분류되며 다시 복구하지 않는다.
