# KRX 수기 다운로드 스테이징 폴더

pykrx(봇)가 KRX에 차단돼 수급(F3)·공매도(F4)를 자동 수집할 수 없다(2026-09-30 확인).
**사람이 브라우저로 `data.krx.co.kr`(KRX 정보데이터시스템)에 로그인하면 CSV 내보내기가
되므로**, Sean이 직접 받은 원본 CSV를 이 폴더에 둔다. Claude/Codex가 이 원본을 읽어
`data/factor_log.csv`에 병합하는 임포터를 짠다.

## ⚠ 규칙

- **`data/factor_log.csv`를 직접 편집하지 말 것.** 32컬럼·파생값이라 손대면 깨진다.
  원본 CSV만 이 폴더에 두면 임포터가 검증(사본·해시 대조)하며 병합한다.
- **다운로드한 원본을 그대로 둘 것.** 컬럼명·인코딩(보통 EUC-KR/CP949)을 바꾸지 말 것.
  임포터가 실제 헤더에 맞춰 파싱한다.
- 파일을 넣은 뒤 **첫 줄(헤더)을 Claude/Codex에게 알려주면** 그에 맞춰 파서를 짠다.

## 파일 이름 규칙

| 데이터 | 파일명 | KRX 메뉴 | 받을 때 |
|---|---|---|---|
| **수급(F3)** | `krx_investor_402340.csv` | 투자자별 거래실적 → 개별종목 | 종목 402340, 기간 20211129~현재, **"거래대금" 기준**(거래량 아님 — 기존 factor_log 단위와 맞추려면) |
| **공매도(F4)** | `krx_short_402340.csv` | 공매도 통계 → 개별종목 공매도 종합정보 | 종목 402340, 같은 기간, 잔고수량·잔고금액·잔고비율·공매도거래량·비중 |

- 한 번에 전 구간이 안 받아지면(KRX가 조회 기간을 제한하면) 연도별로 나눠 받아
  `krx_investor_402340_2021.csv`, `..._2022.csv` … 처럼 접미사를 붙여도 된다.
  임포터가 여러 파일을 날짜로 합친다.

## 매핑 목표 (factor_log 컬럼)

- 수급 → `foreign_net`, `institution_net`, `individual_net`(거래대금 원), `foreign_own_pct`
- 공매도 → `shorting_balance`(잔고수량), `shorting_balance_ratio`(잔고율%),
  `shorting_volume_ratio`(당일 공매도 비중%), `shorting_balance_change`(잔고 전일대비, 임포터가 계산)

이 원본으로 채우면 §5의 "네이버 수량 → 원 환산 추정" 문제 자체가 사라진다
(KRX 거래대금은 기존과 같은 정의·단위).
